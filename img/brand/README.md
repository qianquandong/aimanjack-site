# AI Man Jack brand kit

Generated by `node scripts/brand-kit.mjs` from the same mark as `/favicon.svg` (ink `#1D1A19`, accent `#A8552F`, Satoshi 800). Edit the script, not the PNGs.

| File | Use it for |
|---|---|
| `avatar-dark-1024.png` | Business-account avatar on any platform that crops to a circle: Google Business Profile logo, Nextdoor, Instagram, Bing Places |
| `avatar-light-1024.png` | Same, where a light avatar reads better |
| `logo-mark-1024.png`, `logo-mark-512.png` | The rounded-square mark: slides, documents, event posters, Luma event covers |
| `logo-horizontal-dark.png` / `-light.png` | Mark + wordmark, transparent; dark is for light backgrounds, light for dark backgrounds |
| `banner-youtube-2560x1440.png` | YouTube channel banner (content inside the 1546×423 safe area) |
| `banner-linkedin-1584x396.png` | LinkedIn profile background (content right-aligned, clear of the profile photo) |
| `banner-facebook-1640x624.png` | Facebook cover |
| `banner-x-1500x500.png` | X / Twitter header |

Personal profiles (LinkedIn, Luma, Threads, GitHub, YouTube "Jack Builds AI") keep Jack's headshot as the avatar and use the banner; business profiles use the avatar.
