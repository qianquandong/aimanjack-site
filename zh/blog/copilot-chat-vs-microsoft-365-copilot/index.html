Copilot Chat 和 Microsoft 365 Copilot：团队应该先学哪一个？

用 Microsoft 365 的公司，大多已经有其中一个，正在考虑要不要为另一个付费。每个人手里到底是哪个版本，决定了培训怎么排。

核心要点
  • Copilot Chat 是微软随符合条件的 Microsoft 365 方案提供的、基于网页信息的工作版对话；Microsoft 365 Copilot 是付费许可证，还能基于你自己的邮件、文件、会议和聊天来回答。
  • 根据微软的 Copilot Chat 常见问题，没有许可证时，Copilot Chat 只能看到本人提供给它的公司内容，比如上传的文件。
  • 有许可证时，微软说明 Copilot 只会呈现用户本来至少有查看权限的组织数据，所以共享过度的文件夹会更快暴露出来。
  • 大多数人还没有许可证的话，先用 Copilot Chat 培训：写提示词和核验输出的习惯，加了许可证之后照样适用。
  • 买许可证之前，让每个团队用 Copilot Chat 跑两周真实任务；总要去别处找工作数据的那些任务，才是许可证真正有用的地方。

开课十分钟内一定会被问到的问题

Copilot Chat 和 Microsoft 365 Copilot 先学哪个，是我们 Microsoft Copilot 团队培训开课就要回答的问题。第一个模块叫“Copilot Chat 与应用内 Copilot”，放在最前面，是因为这两个很容易混淆：免费的工作版对话和付费许可证看起来差不多，能读到的数据却不一样。两者的区别决定了每个人能练什么，所以在写第一句提示词之前先讲清楚。

名字帮不上忙。两个都叫 Copilot，都出现在浏览器和 Microsoft 365 应用里，都是在对话框里回答。真正的区别在于各自能读到什么。

两个版本各自能读到什么

Copilot Chat 是微软给使用工作账号（Entra）登录、且所在 Microsoft 365 方案符合条件的员工提供的工作版对话，微软称它基于网页信息回答。微软的 Copilot Chat 常见问题写明：没有 Microsoft 365 Copilot 许可证时，它访问不到公司共享数据、个人的邮箱和文件，也访问不到 Graph 连接器的数据。它处理的是你给它的东西：粘贴的文字、上传的文件。

Microsoft 365 Copilot 是付费许可证。微软的 Copilot 概览说它基于网页信息加上通过 Microsoft Graph 获取的工作数据来回答，而且在有许可证的账号上，它出现在 Word、Excel、PowerPoint、Outlook 和 Teams 里面。所以它能直接总结一串邮件，不用人先复制粘贴，也能把一场 Teams 会议整理成纪要。

有许可证的版本，也只能读到本人原本就能打开的内容。微软的数据、隐私与安全说明写道：Copilot 只呈现用户至少有查看权限的组织数据。落到实际，就是两年前设成“所有人可见”的 SharePoint 站点，现在问一句就能翻出来。这也是我们的 Copilot 课在数据部分先讲“哪些站点和文件夹在范围内”的原因。

智能体是第三层。同一份常见问题说，能读取 SharePoint 或 Graph 连接器内容的智能体按用量计费，且默认关闭；只基于指令和公开网站搭建的简单智能体看不到公司内部数据。价格和方案细节变化很快，我们不在这里写数字，请到微软的价格页面查看你们的方案。

怎么决定团队先学哪个

  1. 先弄清谁有什么。问 IT 负责人四个问题：谁有 Microsoft 365 Copilot 许可证、哪些应用开了 Copilot、Teams 会议转录是否开启、是否允许使用智能体。我们的 Copilot 培训页上写的课前 15 分钟通话，就是问这四件事。
  2. 每人列一项每周重复的任务。每周状态报告、会议纪要、对同一个客户问题的回复。在每项旁边写上：输入是本人可以粘贴或上传的东西，还是分散在邮件、文件和会议里的东西。
  3. 能粘贴或上传的任务，用 Copilot Chat 练。根据上传的文档起草、按不同读者改写、从 PDF 里提取字段。这些都不需要许可证，而写提示词的习惯（角色、资料来源、格式、核验）和有许可证的版本完全一样。
  4. 标出总要去找工作数据的任务。如果一个人得先打开四封邮件和一张表格再粘贴进去，这就是许可证能改变的任务。会议纪要是最明显的一个：我们的会议记录转行动项工作流在两个版本里都能跑，但只有带许可证的版本会自己去读 Teams 转录。
  5. 开通许可证之前先清理共享。许可证能读到本人能打开的一切，所以先请 IT 把对全公司共享的站点过一遍。AI 数据边界一页纸列的是两个版本里都绝不能进提示词的内容。
  6. Excel 用真实数字练，然后核对。有许可证时，Copilot 直接处理打开的工作簿；用 Copilot Chat 时，上传一份去掉敏感列的导出表。无论哪种，数字进报告之前，每个人都要对照原始数据核对合计。
  7. 两周后复盘。每项任务问三件事：用在真实工作上了吗？结果够不够用？是否需要 Copilot Chat 读不到的数据？最后一个问题的答案数一数，再决定买多少个许可证。

什么时候这套方法不灵

公司还没决定 Copilot 是批准的工具时，这套方法不灵。如果一半人在用个人账号的 ChatGPT，另一半在用 Copilot Chat，第一件事是选定一个，并写清楚哪些内容可以放进去，AI 工具审批清单就是做这个的。在大家都没达成一致的时候同时教两个工具，哪个都教不好。

文件本身有问题时也不灵。如果最新的价目表、制度和流程散落在每个人自己的 OneDrive 里，许可证找到旧版本和新版本的概率一样高。这是整理文档的活，要在 Copilot 培训之前做。

如果团队的工作大部分不在 Microsoft 365 里，买许可证也不对症。真正的工作在 CRM、业务系统或纸质表格里的话，Outlook 里的 Copilot 够不着。什么时候值得冒险去连接其他系统，可以看我们的 ChatGPT 和 AI agent 怎么选。

接下来 14 天能做的

  • 把上面四个问题问 IT，答案写在一页纸上。15 分钟。
  • 请三个人各拿一项每周任务，用 Copilot Chat 做三次，每次需要手动去别处找东西时记一笔。
  • 导出对全公司共享的 SharePoint 站点清单。如果很长，在分配任何许可证之前先排上清理。

常见问题

Copilot Chat 和 Microsoft 365 Copilot 有什么区别？

Copilot Chat 是随符合条件的 Microsoft 365 方案提供、基于网页信息的工作版对话，只能看到你粘贴或上传的公司内容。Microsoft 365 Copilot 是付费许可证，还能通过 Microsoft Graph 读取本人的邮件、文件、会议和聊天，并在 Word、Excel、PowerPoint、Outlook 和 Teams 里使用。

企业用 Copilot Chat 要付费吗？

微软的说法是，使用工作账号登录、方案符合条件的员工可以使用 Copilot Chat，不额外收费；其中部分智能体按用量计费。具体以微软价格页面上你们方案的说明为准。

买 Microsoft 365 Copilot 许可证之前要先培训员工吗？

要，用 Copilot Chat 先练。写提示词和复核的习惯是一样的，跑两周真实任务，就能看出哪些任务总需要邮件、文件或会议数据，而这正是许可证增加的能力。

Microsoft 365 Copilot 会让员工看到不该看的文件吗？

微软说明 Copilot 只呈现用户本来至少有查看权限的组织数据。如果文件共享过度，Copilot 就能把它翻出来，所以分配许可证之前先检查全公司范围的共享设置。

你们在达拉斯做 Copilot 培训吗？

做。可以到达拉斯—沃斯堡各地的公司现场上课，也可以全美线上直播，中英文都行，用每个人手里实际的 Copilot 版本来教。每个团队单独书面报价。
