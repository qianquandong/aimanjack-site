Copilot Chat vs Microsoft 365 Copilot: which one should your team learn first?

Most companies on Microsoft 365 already have one of the two and are deciding whether to pay for the other. The training plan changes depending on which one each person actually has.

Jack Qian · Published October 17, 2026

Key takeaways
  • Copilot Chat is the web-grounded work chat Microsoft includes with eligible Microsoft 365 plans; Microsoft 365 Copilot is the paid license that also grounds answers in your own email, files, meetings and chats.
  • Without the license, Copilot Chat only sees company content a person gives it, for example a file they upload, according to Microsoft’s Copilot Chat FAQ.
  • With the license, Microsoft states that Copilot only surfaces organizational data the user already has at least view permission to, so over-shared folders become visible faster.
  • Train on Copilot Chat first if most people have no license yet: the prompt habits and the checking habits carry over unchanged when a license is added.
  • Before buying licenses, have each team run one real task in Copilot Chat for two weeks; the tasks that kept needing work data are the ones a license is for.

The question that comes up in the first ten minutes

The first module of our Microsoft Copilot training is called “Copilot Chat vs. Copilot in the apps”, and it comes first because the two are easy to confuse: the free work chat and the paid license look alike but reach different data. The Copilot Chat vs Microsoft 365 Copilot question decides what each person can practise, so we answer it before anyone writes a prompt.

The names do not help. Both say Copilot, both show up in the browser and in the Microsoft 365 app, and both answer in a chat window. The difference is what each one can read.

What each one can read

Copilot Chat is the work chat Microsoft includes for people who sign in with a work (Entra) account on an eligible Microsoft 365 plan. Microsoft describes it as grounded in the web. Its Copilot Chat FAQ says that without a Microsoft 365 Copilot license it cannot reach shared company data, a person’s own mailbox and files, or data from Graph connectors. It works on what you give it: text you paste, a file you upload.

Microsoft 365 Copilot is the paid license. Microsoft’s Copilot overview describes it as grounded in the web plus your work data through Microsoft Graph, and it is the version that appears inside Word, Excel, PowerPoint, Outlook and Teams on the licensed account. That is what lets it summarize a thread without anyone pasting it, or turn a Teams meeting into a recap.

The licensed version only reads what the person could already open. Microsoft’s data, privacy and security page says Copilot only surfaces organizational data to which individual users have at least view permissions. In practice that means a SharePoint site shared with “everyone” two years ago is now one question away, which is why the data part of our Copilot sessions starts with which sites and folders are in scope.

Agents are a third layer. The same FAQ says agents that reach SharePoint or Graph connector content are metered and switched off by default, while simple agents built only on instructions and public websites cannot see tenant data. Price and plan details change often, so we do not print them; check Microsoft’s pricing page for your plan.

How to decide what your team trains on

  1. Find out who has what. Ask your IT lead four questions: who has a Microsoft 365 Copilot license, which apps have Copilot enabled, whether Teams meeting transcription is on, and whether agents are allowed. On our Copilot page that is the 15-minute call we ask for before a session.
  2. List one weekly task per person. The weekly status report, the meeting recap, the reply to the same customer question. Write next to each one whether the input is something the person can paste or upload, or something that lives across email, files and meetings.
  3. Run the paste-or-upload tasks in Copilot Chat. Drafting from a document someone uploads, rewriting for a different reader, pulling fields out of a PDF. None of these need the license, and the prompt habits (role, source, format, check) are the same ones the licensed version uses.
  4. Mark the tasks that kept needing work data. If the person had to open four emails and a spreadsheet and paste them in, that is a task the license would change. Meeting recaps are the obvious one; our meeting notes to action items workflow runs in either version, but only the licensed one reads the Teams transcript for you.
  5. Clean up sharing before licenses go live. Because the license reads everything a person can open, have IT review the sites shared with the whole company first. The AI data boundaries one-pager is the list of what never goes into a prompt in either version.
  6. Train Excel on real numbers, then check them. In the licensed version Copilot works on the open workbook; in Copilot Chat you upload an export with sensitive columns removed. Either way, each person checks totals against the source before the number goes into a report.
  7. Review after two weeks. For each task: was it used on real work, was the output good enough, and did it need data Copilot Chat could not reach? Count those last answers before deciding how many licenses to buy.

When this does not work

It does not work if the company has not decided Copilot is the approved tool. If half the team uses ChatGPT on personal accounts and the other half uses Copilot Chat, the first job is picking one and writing down what may go into it; the AI tool approval checklist is for that. Training two tools at once to people who have not agreed on either teaches neither.

It also does not work when the files are the problem. If the current price list, policy and procedure are scattered across personal OneDrives, a license will find old versions as readily as new ones. That is a documentation job, and it comes before any Copilot training.

And a license is the wrong fix for a team whose work is mostly outside Microsoft 365. If the real work lives in a CRM, a line-of-business system or paper forms, Copilot in Outlook will not reach it. Our ChatGPT vs AI agents guide covers when connecting other systems is worth the risk.

What to do in the next 14 days

  • Ask IT the four questions above and write the answers on one page. Fifteen minutes.
  • Have three people each run one weekly task in Copilot Chat, three times, and note every time they had to go and fetch something by hand.
  • Pull the list of SharePoint sites shared with everyone in the company. If it is long, schedule the cleanup before any license is assigned.

Questions people ask

What is the difference between Copilot Chat and Microsoft 365 Copilot?

Copilot Chat is a web-grounded work chat included with eligible Microsoft 365 plans; it only sees company content you paste or upload. Microsoft 365 Copilot is a paid license that also reads the person’s own email, files, meetings and chats through Microsoft Graph and works inside Word, Excel, PowerPoint, Outlook and Teams.

Is Copilot Chat free for businesses?

Microsoft describes Copilot Chat as available at no additional cost for people signed in with a work account on an eligible Microsoft 365 plan. Some agents inside it are metered. Check Microsoft’s pricing page for what applies to your plan.

Should we train employees before buying Microsoft 365 Copilot licenses?

Yes, on Copilot Chat. The prompt and review habits are the same, and two weeks of real use shows which tasks keep needing email, files or meeting data, which is what the license adds.

Can Microsoft 365 Copilot see files an employee should not see?

Microsoft states that Copilot only surfaces organizational data the user already has at least view permission to. If a file is over-shared, Copilot can surface it, so review company-wide sharing before assigning licenses.
