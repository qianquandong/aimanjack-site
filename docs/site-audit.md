# Site audit — aimanjack.com (2026-09-18)

Input: "Frontend + SEO/GEO + Free Tools Implementation PRD" (given in chat 2026-09-18, direction: *look like Notion, grow like Ahrefs*). This audit describes the repo as it stands after the same-day repositioning deploy (`PRD.md`, commits `3d692c9`…`8c4a11f`), lists every conflict between the two, records the decisions taken, and ends with the P0/P1/P2 checklist.

## 1. Architecture as found

| Area | Finding |
|---|---|
| Framework | None. Zero-dependency static generator: `src/pages/*.mjs` export route objects → `scripts/build.mjs` → `render()` in `src/layout.mjs` → HTML files committed at the repo root. No `package.json`, no bundler, no TypeScript, no linter. |
| Routing | A route is `{ path, priority?, changefreq?, indexable?, en, zh }`. One module can emit many routes (blog, industries). `indexable:false` → `noindex,follow` + out of sitemap. |
| Components | Template-literal functions in `src/components.mjs` (`pageHero`, `faq`, `finalCta`, `breadcrumb`, cards…) and `src/layout.mjs` (`planBtn`, `emailBtn`, header, footer, sticky CTA). About 60% of `components.mjs` is legacy receptionist blocks used only by noindex pages. |
| Content model | Blog only: `src/posts/<slug>.mjs` = one content object (en+zh) → `src/blog.mjs` renders page + Article/FAQ/Breadcrumb JSON-LD → auto sitemap. **This is already the "content object → template → metadata → schema → sitemap" pipeline the PRD asks for**; it just exists for one content type. |
| Styling | One hand-written `style.css` (31 KB raw, ~6.5 KB brotli after deploy-time minify). Tokens on `:root`: `--bg --bg-soft --ink --muted --line --accent` (one blue) `--r:16px --rc:10px`. Satoshi self-hosted, variable 300–900. Breakpoints 1000/900/720/480/400. `prefers-reduced-motion` and `prefers-contrast` handled. The file header literally calls the system "Quiet AI: neutral system, one blue accent" — it already matches the Notion-inspired direction; no token rewrite is needed. |
| Hosting / deploy | Cloudflare Pages, direct upload via `sh deploy.sh` (stages to `.deploy/`, minifies CSS, rewrites `style.css?v=` to a content hash, `wrangler pages deploy`, then IndexNow ping with every sitemap URL). Branch name decides prod vs preview. |
| Backend | Pages Function `functions/v1/[[route]].js`: booking API (+ a coupon endpoint), data in Supabase, confirmation email via Cloudflare Email Sending. Untouched by this PRD. |
| Analytics | GA4 `G-H7EF9HVN02`, loaded after `load`, production hostname only. Event delegation on `[data-event]` with `cta_position/page/language/device`. |
| SEO | Per page: title, description, self canonical, hreflang en/zh/x-default, OG + Twitter, robots meta. JSON-LD from `src/schema.mjs` (ProfessionalService, Person, WebSite, FAQPage, BreadcrumbList, Article). Sitemap and `llms.txt` generated by the build. `robots.txt` allows all + names AI crawlers. `_redirects` maps 16 old URLs. |
| Quality gates | `node --test tests/` (9 tests: metadata, banned receptionist phrases, unique title/description, orphans, sized images, legacy noindex, llms) and `node scripts/health.mjs` against production (daily scheduled task). |
| i18n | Every route is rendered twice (EN + `/zh/…`), copy written side by side. |
| Pages live | Indexable: `/`, `/ai-training/`, `/blog/` + 1 post, `/about/`, `/contact/`, `/book/`, 3 legal = 10 EN + 10 ZH. Legacy noindex: `/ai-receptionist/`, `/pricing/`, `/industries/*` (6), `/integrations/`, `/tools/missed-call-calculator/`, `/case-studies/*` (3), 1 blog post. |
| Link health | 52 HTML files, 978 internal hrefs, **0 broken**. |
| Performance | No framework JS. One inline script (~1 KB). Home = hero photo (responsive WebP, `fetchpriority=high`) + CSS. Last recorded mobile Lighthouse 100 / LCP ≈1.5 s (2026-09-02, deploy.sh comment). Risk is low; the only thing that can hurt is adding client JS for tools/search — keep it inline and small. |
| Technical debt relevant here | (1) legacy blocks bloat `components.mjs`; (2) `HEALTH-CHECK.md` funnel definitions are pre-pivot; (3) no content types besides blog; (4) header nav has two anchor links (`Workshops`, `Teams`) that land on the same page as `AI Training`; (5) home and `/ai-training/` share hero image, proof strip and section order, so they read as the same page. (4) and (5) were raised by Jack on 2026-09-18 and are resolved by this PRD's nav and homepage. |
